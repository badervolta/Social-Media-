Assumptions

  • One company account per platform: a LinkedIn page, a Facebook page and an Instagram business profile.
  • Amy is the only reviewer. A real tool might add a second approver.
  • Volta's time zone is Atlantic (AST). The digest window is 1:00 p.m. to 1:00 p.m.
  • Urgent means media requests, billing problems, stated deadlines and possible inappropriate content.
  • The voice is warm, short and plain, with Canadian spelling and a personal sign-off.

Safety rules built in

  • No social accounts connected yet. Data is stored in Supabase and only signed-in, invited Volta staff can read it.
  • The browser can never delete real data, edit message content, or send anything.
  • No reply can be approved while it still contains a [placeholder].
  • Offensive comments are blurred until you choose to read them.
  • Every action is written to the item's activity history.
